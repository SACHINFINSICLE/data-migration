# Header Mapping Tool - Installation Guide

This guide will help you install and run the Header Mapping Tool on your computer.

## For Mac Users

1. Extract all files from the zip file to a folder
2. Open Terminal:
   - Press `Command + Space` to open Spotlight
   - Type "Terminal" and press Enter
3. In Terminal, navigate to the extracted folder:
   ```bash
   cd path/to/extracted/folder
   ```
4. Make the start script executable:
   ```bash
   chmod +x start_app.sh
   ```
5. Run the application:
   ```bash
   ./start_app.sh
   ```
6. The application will open in your default web browser

## For Windows Users

1. Extract all files from the zip file to a folder
2. Double-click the `start_app.bat` file
3. The application will open in your default web browser

## Using the Application

1. Upload your template Excel file
2. Upload your customer data Excel file
3. Map the headers between the two files
4. Download the transformed file

## Troubleshooting

If you encounter any issues:
1. Make sure all files are extracted to the same folder
2. Try running the application as administrator (Windows)
3. Contact technical support if issues persist

## Notes

- The application runs locally on your computer
- No internet connection required
- Your data stays on your machine
- Files are processed in memory for security
